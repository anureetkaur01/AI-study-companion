================================================================================
  AI STUDY COMPANION - STARTUP INSTRUCTIONS
================================================================================

--------------------------------------------------------------------------------
OPTION 1: One-Click Startup (Easiest)
--------------------------------------------------------------------------------
Simply double-click the file named:
  start-app.bat

This will automatically:
  1. Launch the Backend server in its own window (Port 5000)
  2. Launch the Frontend server in its own window (Port 3000)
  3. Open your browser directly at http://localhost:3000


--------------------------------------------------------------------------------
OPTION 2: Manual Step-by-Step Startup
--------------------------------------------------------------------------------

STEP 1: Ensure MongoDB is Running
  1. Check if MongoDB is running:
       Get-Service MongoDB
  2. If it is stopped, start it:
       net start MongoDB
     (or in PowerShell: Start-Service MongoDB)

STEP 2: Start the Backend Service
  1. Open a new Terminal / PowerShell window.
  2. Navigate to the backend directory:
       cd backend
  3. Run the development server:
       npm run dev

     * Backend runs at: http://localhost:5000
     * Health check:    http://localhost:5000/api/health

STEP 3: Start the Frontend Service
  1. Open a SECOND Terminal / PowerShell window.
  2. Navigate to the frontend directory:
       cd frontend
  3. Run the frontend server:
       npm run dev

     * Frontend runs at: http://localhost:3000

STEP 4: Open in Your Browser
  Visit: http://localhost:3000


--------------------------------------------------------------------------------
STOPPING THE SERVERS
--------------------------------------------------------------------------------
To stop either server at any time:
  Press Ctrl + C in the corresponding terminal window and type 'Y'.
